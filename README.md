# Примерный план работы
- сбор и анализ литературы
- постановка гипотез для идентификации проблем и особенностей
- проверка гипотез и эксперименты
- предложение решения найденной проблемы и связанные с этим эксперименты
- реализация ML-сервиса на FastAPI, который принимает данные, выполняет инференс обученной модели и возвращает результат в заданном формате
